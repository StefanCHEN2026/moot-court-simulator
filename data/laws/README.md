# 法规数据

庭审界面的「法律条文」侧边栏从这里读取数据。**本项目不附带法规正文**，默认返回空列表，不影响庭审主流程。

## 文件

| 文件 | 用途 |
| --- | --- |
| `domestic.json` | 国内法律法规（对应 `/api/laws`） |
| `arbitration.json` | 国际仲裁规则（对应 `/api/laws?type=arbitration`） |

数据目录可通过环境变量 `LAWS_DATA_DIR` 指向其他位置。

## 数据格式

两个文件都是「法律条目」数组：

```json
[
  {
    "id": "civil-procedure-law",
    "name": "中华人民共和国民事诉讼法",
    "chapters": [
      {
        "id": "chapter-1",
        "name": "第一章 总则",
        "articles": [
          "第一条 中华人民共和国民事诉讼法以宪法为根据，结合我国民事审判工作的经验和实际情况制定。",
          "第二条 中华人民共和国民事诉讼法的任务，是保护当事人行使诉讼权利……"
        ]
      }
    ]
  }
]
```

字段说明：

- `id`：法律唯一标识（建议用英文短横线命名）。
- `name`：显示名称。
- `chapters[].id` / `chapters[].name`：章标识与标题。
- `chapters[].articles`：条文文本数组，每条建议包含条号（如 `第一条 …`），前端按纯文本包含匹配来搜索。

## 填充数据

任选一种方式：

1. 手工整理：按上述格式编辑 `domestic.json` / `arbitration.json`。
2. 从公开数据源转换：把法规正文转成上述 JSON 结构后写入即可，无需改动代码。

> 注意：请确保所引入法规文本的准确性，并遵守数据来源的使用条款。条文以官方发布版本为准。
